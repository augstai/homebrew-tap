# August Cyber Homebrew Tap

Install the [August Cyber](https://august.so) CLI on macOS or Linux via Homebrew:

```bash
brew install augstai/tap/august
```

Or tap first and install:

```bash
brew tap augstai/tap
brew install august
```

## Verify Installation

```bash
august --version
august --help
```
